If downloads fail with a CORS error, the remote server is blocking browser requests. Two ways to fix it:

Locally: run node proxy.js in a terminal, then paste http://localhost:8079/ above.

Deployed (e.g. on Vercel): if this app and api/proxy.js are deployed together, paste https://your-app.vercel.app/api/proxy?url= above — works from any device, no terminal needed.

Alternatively, install a browser extension that disables CORS checks: CORS Everywhere for Firefox or Allow CORS for Chrome — then you don't need the proxy field at all.
